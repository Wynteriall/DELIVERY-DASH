# ADR 0005: Resolution is 1920×1080 with viewport stretch

## Status
Accepted

## Context
The SPEC originally called for 640×360 with `canvas_items` stretch. The first collaborator commit authored every gameplay scene (map, props, collision polygons, HUD offsets) at 1920×1080 scale, and set `project.godot` accordingly.

## Decision
Amend the SPEC to 1920×1080 with `viewport` stretch. All authored scenes stay as built.

## Consequences
- Re-scaling scenes to 640×360 (or the HUD to canvas_items) is abandoned for now — high effort, no player-visible gain.
- Pixel-art assets at 32×32/16×16 will be scaled up per-node (already the pattern in `game.tscn`).
- Reversible: a future pass can re-target 640×360 by re-laying out scenes if playtests demand it.
