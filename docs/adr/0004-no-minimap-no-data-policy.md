# ADR 0004: Remove minimap and Data Policy screen

## Status
Accepted

## Context
The original plan included a static Piskel minimap with a moving player dot and a Data Policy pop-up panel on the main menu. During implementation planning these were dropped.

## Decision
Remove the minimap and the Data Policy panel. Main menu is reduced to Start, Settings, Credits.

## Consequences
- Fewer screens to build and maintain.
- Main menu click areas only needed for Start, Settings, Credits.
- Reversible if the instructor or playtesting requires them back.
